# AI & LLM Learning Plan

A hands-on learning repository documenting my journey from AI fundamentals to advanced Large Language Models (LLMs), Transformers, and practical AI application development.

The goal of this project is to understand how modern LLMs work internally and build practical AI applications using Python.

## 📚 Learning Roadmap

| Module | Topic | Focus |
|---|---|---|
| 01 | LLM Fundamentals | AI evolution, LLM pipeline, next-token prediction |
| 02 | Pretraining and Data | Web crawling, data cleaning, deduplication, datasets |
| 03 | Tokenization | Tokens, token IDs, BPE, tokenizers |
| 04 | Neural Networks and Transformers | Embeddings, attention, Q/K/V, positional encoding |
| 05 | Inference and Sampling | Temperature, Top-K, Top-P |
| 06 | Base Models | GPT, Llama, in-context learning |
| 07 | Post-Training | Supervised fine-tuning and human feedback |
| 08 | LLM Psychology | Hallucinations, reasoning, tool usage |
| 09 | Reinforcement Learning | RLHF, GRPO, reasoning models |
| 10 | LLM Applications | RAG and AI application development |
