 API Integration

## Overview

This project demonstrates how to integrate Large Language Models (LLMs) into Python applications using APIs.

The objective is to understand how Python applications communicate with LLMs, send requests, receive responses, manage tokens, and implement practical AI functionalities.

## Technologies Used

- Python
- OpenAI API
- OpenAI Python SDK
- Python-dotenv

## Project Structure

```text
11_api_integration/
│
├── main.py
├── .env
├── .gitignore
└── README.md
```

## Features

- LLM API integration
- Sending user prompts to an LLM
- Receiving AI-generated responses
- Input and output token tracking
- Environment variable management

## Learning Objectives

1. Understanding API integration.
2. Understanding API requests and responses.
3. Learning how to use the OpenAI Python SDK.
4. Understanding input and output tokens.
5. Managing API credentials securely.
